Q3. Composition vs inheritance in React — why does React push composition?

Simplified Question (Much Easier 😊):
"What's the difference between building components by combining smaller parts (composition) vs extending/inheriting from other components (inheritance), and why does React prefer one over the other?"

A3. Composition in React 💻
In React, composition means:

Build small, simple components
Combine them to make bigger components
Reuse small pieces in different ways
